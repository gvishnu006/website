# My Website

A simple, fast, and responsive static website built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact

## Usage

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 8000
# or
npx serve .
```

## Deployment

Can be deployed to GitHub Pages or any static file host:

```bash
git push origin main
```

Then enable GitHub Pages in the repository settings (use the `main` branch).
